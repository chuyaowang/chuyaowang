# Hi, I'm Chuyao 👋

I'm a bioinformatics and systems biology graduate interested in biomedical AI research. Follow links below for my bioinformatics and hobby projects. A quick overview is available in their readme.

## 🎓 Research Project

### [Master's Thesis](https://github.com/chuyaowang/c_albicans_project)

My master's thesis project building a segmentation + cell-cell relationship classification pipeline for single-cell microscopy using the foundational model [microSAM](https://github.com/computational-cell-analytics/micro-sam) and a graph attention network.

### [Napari Classifier](https://github.com/chuyaowang/napari-rf)

A Napari plugin to make pixel-level classifications (ex. cell vs. background) using a random forest model trained from user labels.

## 📖 Course Projects

### [Course projects from Master's](https://github.com/chuyaowang/master-course-projects)

Highlight figures from multi-omics analysis and machine learning course projects during my Master's at VU and UvA.

### [scRNA and scATAC Analysis](https://github.com/chuyaowang/single-cell-course-2022)

Jupyter notebooks from a hands-on course on scRNA and scATAC data analysis.

### [Spatial RNA-seq Analysis](https://github.com/chuyaowang/spatial-omics-course-2023)

Jupyter notebooks from a hands-on course on spatial RNA-seq data analysis.

## 💡 Miscellaneous Projects
